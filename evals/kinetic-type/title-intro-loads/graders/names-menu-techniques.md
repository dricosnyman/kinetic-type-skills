The response is a plan or code for a short Remotion title animation.

PASS if the plan or code names, or clearly builds, at least one technique from the menu below, beyond a plain fade, a plain slide or a plain pop/scale-in, chosen for what the words mean. The reason can be stated (in the plan, a code comment or the reply) or obvious from the pairing (for example slicing the title for fractions, or a friendly bounce for "friends"). One well-chosen technique is enough; variety is not required.

Close synonyms count (for example "letters stagger in one by one" counts as cascade; "a highlighter bar sweeps behind the word" counts as marker highlight).

FAIL if the only text animation is fade, slide or pop/scale (alone or combined), if no technique from the menu appears, or if the menu technique has no connection to what the words mean.
